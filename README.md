# Smeshariki / Dust Strike

Сайт игры: https://kubok758.github.io/Smeshariki-Dust-Strike/

Лёгкий адаптивный сайт для скачивания Android-версии. Реальные игровые кадры, локальные шрифты, увеличение скриншотов, инструкция по установке. Без сборщика, аналитики, cookie и внешних UI-библиотек.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`. `.nojekyll` отключает обработку Jekyll. Все внутренние пути относительные и работают в каталоге проекта.

APK размещается на MEGA. Кнопки открывают публичную ссылку на файл в новой вкладке. APK, игровые исходники и ключ подписи в этот репозиторий не входят. GitHub Releases и внешний API не используются.

## Обновление игры

1. Загрузить подписанный APK на MEGA и получить публичную ссылку на файл вместе с ключом: `https://mega.nz/file/…#…`. Проверить, что ссылка открывается без входа в аккаунт и скачивает нужную версию.
2. Обновить локальный `release.json`: `version`, `publishedAt` в формате `YYYY-MM-DD`, точный размер в байтах `apkBytes`, полный адрес `downloadUrl` и список `changes`.
3. Синхронно обновить статический резерв в `index.html`: версию, дату, размер, изменения, три ссылки `.download-link` и их подписи `.download-label`. Для готового файла у всех трёх ссылок должны быть `href` с полным адресом MEGA, `target="_blank"` и `rel="noopener noreferrer"`. Изменить `.release-state` на «ГОТОВО К УСТАНОВКЕ», `.release-badge` на «LIVE», а `#release-status` — на инструкцию о скачивании с MEGA. Так скачивание работает и без JavaScript или при сбое загрузки JSON.
4. Опубликовать оба файла в `main`, дождаться GitHub Pages и проверить кнопки на телефоне и компьютере.

Пока файл не опубликован, `downloadUrl` должен оставаться пустым. В статическом HTML у кнопок остаётся `href="#download"`, подпись «Ссылка готовится» и сообщение о подготовке файла. Не подставлять предположительные ссылки. Текущий APK: 1.8.4. Публичная ссылка MEGA указана в release.json и статическом HTML.

## Локальный просмотр

Запустить любой статический HTTP-сервер в корне, например `python -m http.server 8080`, и открыть http://localhost:8080 .

Изображения — реальные кадры из игры. Лицензии используемых шрифтов лежат рядом с файлами шрифтов в `assets`.
